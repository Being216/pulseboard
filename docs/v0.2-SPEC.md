# pulseboard v0.2 SPEC — 实现规格（给 codex）

> 2026-09-08 19:20 由 haitian 起草。PRD 见 docs/PRD.md。在 v0.1 基础上新增三块：任务操作语义、human_edited 冲突处理（方案A）、提醒按钮。

## 现状（v0.1）

- `server.py`：GET / 返回 index.html（记 visit），GET /api/tasks 返回 tasks.json
- `index.html`：三态展示任务卡片，30s 轮询
- `tasks.json`：顶层 `being/updated_at/last_heartbeat_at/is_working/current_activity/tasks[]`，每个 task 有 `id/title/status/summary/milestones[]/next`

## v0.2 新增

### 1. server.py 新增端点（全 POST，JSON body）

**POST /api/tasks/:id/edit**
- body: `{title?, summary?, next?, status?}`（只允许这四个字段）
- 合并写入 tasks.json 对应 task
- 给该 task 设置 `"human_edited": {"at": "<iso时间>", "fields": ["title","next",...]}`（fields = 本次实际改动的字段）
- 返回 `{ok: true}`

**POST /api/tasks/:id/cancel**
- 把 task 的 `status` 改为 `"cancelled"`，并把该 task 从 `tasks[]` 移入顶层新数组 `"history": []`
- 返回 `{ok: true}`

**POST /api/tasks/:id/refresh**
- 往 `signals.jsonl` 追加一行 `{"type": "refresh", "task_id": "...", "at": "<iso>", "ua": "<User-Agent>"}`
- 返回 `{ok: true}`

**POST /api/tasks/:id/remind**
- 往 `signals.jsonl` 追加一行 `{"type": "remind", "task_id": "...", "at": "<iso>", "ua": "..."}`
- 返回 `{ok: true}`

注意：
- signals.jsonl 是 being（另一个进程）每心跳消费的信号文件，server 只追加不读取不清理
- 所有写操作要原子写（写临时文件再 rename），防止 being 读到半截 JSON
- tasks.json 缺该 id 时返回 404 `{ok: false, error: "task not found"}`
- GET /api/history 新增：返回 history 数组（页面历史栏用）
- 端口仍是 8765，绑定 127.0.0.1

### 2. human_edited 冲突处理（方案 A）

- 人类编辑过的字段，标记进 `task.human_edited.fields`
- being（外部进程，不用你实现）心跳读到后自行吸收并清掉标记；server 端不需要额外逻辑，只要保证 edit 端点正确打标即可

### 3. index.html 交互升级

每个任务卡片底部加一排小按钮（低存在感，hover 才显色）：

- **编辑**：弹出内联编辑区（就在卡片内展开，不要 window.prompt），title / summary / next 三个输入框 + status 下拉（pending/in_progress/blocked/done）+ 保存/取消。保存 → POST edit → 重新 load()
- **取消任务**：confirm 后 POST cancel，卡片消失
- **刷新**：POST refresh，按钮短暂变「已请求」
- **提醒 being**：POST remind，按钮短暂变「已提醒 ⏰」

新增**历史任务栏**：页面底部单独一节「历史」，灰显展示 `history[]` 的任务（只读，只显示 title + status + summary），数据来自 GET /api/history。

卡片上如果 `t.human_edited` 存在，标题旁显示小标记「✋ 已人工编辑」。

保持现有暗色风格，不引入任何外部依赖（无 CDN、无框架，纯原生 JS/CSS）。

### 4. 验收标准（haitian 会逐项测）

1. edit 一个 task 的 next → tasks.json 里 next 更新且 human_edited 正确记录
2. cancel 一个 task → tasks[] 减少、history[] 出现、页面历史栏显示
3. refresh / remind → signals.jsonl 各追加一行且 JSON 合法
4. 页面无外部网络请求（断网可开）
5. python3 -m py_compile server.py 通过；index.html 无 JS 语法错误

## 目录

直接在仓库根目录改 server.py / index.html，tasks.json 是数据文件不动（部署时由 being 同步）。
